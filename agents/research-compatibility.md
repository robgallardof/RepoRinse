# research-compatibility

Checks the official hook documentation of Git, Claude Code, Codex, Gemini CLI, Cursor and Antigravity and records a dated compatibility matrix (event, payload, response, exit codes, fail-open/closed, scope, config paths).

**Owns:** see the wave/ownership table in [docs/architecture/plan.md](../docs/architecture/plan.md).

**Must return:** what was implemented, decisions, files changed, tests run with real results, risks, limitations.

**Acceptance:** Every claim links to an official source with the date checked; unknowns are marked 'pending verification', never assumed.
