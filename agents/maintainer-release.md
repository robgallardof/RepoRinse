# maintainer-release

Prepares CHANGELOG, versioning, packaging, templates and a release dry-run with checksums.

**Owns:** see the wave/ownership table in [docs/architecture/plan.md](../docs/architecture/plan.md).

**Must return:** what was implemented, decisions, files changed, tests run with real results, risks, limitations.

**Acceptance:** Release artifacts are reproducible and checks are green; nothing is published without the maintainer's approval.
