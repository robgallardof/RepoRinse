# test-automation-specialist

Writes independent unit/integration/E2E, regression, property and performance tests and the local CI script.

**Owns:** see the wave/ownership table in [docs/architecture/plan.md](../docs/architecture/plan.md).

**Must return:** what was implemented, decisions, files changed, tests run with real results, risks, limitations.

**Acceptance:** Tests are repeatable, isolated from the developer's machine and never marked passed when skipped.
