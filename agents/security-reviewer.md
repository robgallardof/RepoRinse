# security-reviewer

Threat-models path traversal, symlinks, secrets in logs, destructive fixes and hook bypasses; reproduces attacks as tests.

**Owns:** see the wave/ownership table in [docs/architecture/plan.md](../docs/architecture/plan.md).

**Must return:** what was implemented, decisions, files changed, tests run with real results, risks, limitations.

**Acceptance:** Each attack has a regression test; documentation never presents hooks as an unbreakable security boundary.
