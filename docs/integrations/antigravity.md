# Antigravity

Use `reporinse install --provider git --all --yes` for Git commits made by Antigravity.
Native Antigravity hooks remain unverified and are not installed. `--provider antigravity` returns 69.
This is a compatibility boundary, not a simulated native integration.

## Español

Usa la integración Git para sus commits. No se instalan hooks nativos de Antigravity sin verificación.
