# `git.ai-attribution`

Removes the attribution that AI coding agents add to commit messages — `Co-Authored-By:` trailers of known
agents and whole-line "Generated with …" footers — and keeps everything else: human co-authors, unrelated
trailers, and ordinary text that mentions Claude, ChatGPT, Codex or any other product.

Successor of [no-ai-coauthor](../migration/no-ai-couathor.md). [Español](#español)

| | |
|---|---|
| Id / version | `git.ai-attribution` / 1.0.0 |
| Target | commit messages (`commit-msg` hook, `reporinse hook git commit-msg <file>`) |
| Modes | `off`, `warn`, `block`, `fix` — default **`fix`** |
| Risk / priority | low / P0 |
| Providers | `git`, `cli` |

## What it changes

Before:

```text
feat: add login with magic link

🤖 Generated with [Claude Code](https://claude.com/claude-code)

Co-Authored-By: Claude <noreply@anthropic.com>
Co-authored-by: Ana Pérez <ana@example.com>
```

After (`fix` mode):

```text
feat: add login with magic link

Co-authored-by: Ana Pérez <ana@example.com>
```

Only whole lines are deleted. Every other byte — CRLF or LF newlines, a UTF-8 BOM, Unicode, indentation, blank
lines you wrote — stays exactly as it was. The only extra deletions are the blank lines a removal leaves doubled
(two blank lines become one) or dangling at the end of the message. If the message had no final newline, it
still has none. Running the rule twice changes nothing the second time.

It never touches: the subject line (first non-blank line), Git comment lines (`#`, or `core.commentChar` /
`core.commentString`), anything below the `git commit -v` scissors line, the author, the committer, GPG/SSH
signatures, or commits already in history.

## Co-author decision table

A `Co-authored-by:` line (any capitalization, optional indentation such as `git merge --squash` produces) is
split into a display name and an address. The rule removes it only when it is **sure** it is an agent.

| Display name | Address | Decision | Example |
|---|---|---|---|
| anything | known agent address (list below) | **remove** | `Claude <noreply@anthropic.com>`, `Copilot <198982749+Copilot@users.noreply.github.com>` |
| agent name, alone or + model/version words | anything | **remove** | `Claude Code`, `Claude Opus 4.5`, `ChatGPT`, `aider (gpt-4o)`, `claude[bot]` |
| ambiguous first name alone (`Claude`, `Devin`, `Gemini`, `Jules`) | none | **remove** | `Co-authored-by: Claude` |
| ambiguous first name alone | any other address | **keep** (noted with `--verbose`) | `Claude <claude@dupont.fr>` |
| agent word + other words | not an agent address | **keep** | `Claude Dupont <claude@dupont.fr>`, `Devin Booker <d@b.com>` |
| anything else | not an agent address | **keep** | `Ana <ana@example.com>`, `Jane <jane@anthropic.com>` |

*Agent names* (unambiguous on their own): Aider, Amazon Q (Developer), ChatGPT, ChatGPT Codex Connector,
Claude Code, Codex, Codex CLI, Copilot, Copilot SWE Agent, Cursor, Cursor Agent, Devin AI, Gemini CLI,
Gemini Code Assist, GitHub Copilot, Google Labs Jules, OpenAI, OpenAI Codex, OpenHands, Windsurf. Matching is
case-insensitive and treats `-`, `_`, `(`, `)` as spaces, so `claude-3-7-sonnet` is `claude 3 7 sonnet`.

*Model/version words* allowed after a name: any word containing a digit (`4`, `4.5`, `o3`, `4o`) and `agent`,
`ai`, `assistant`, `bot`, `cli`, `code`, `exp`, `experimental`, `flash`, `haiku`, `high`, `instant`, `latest`,
`lite`, `low`, `max`, `medium`, `mini`, `model`, `nano`, `opus`, `preview`, `pro`, `sonnet`, `thinking`,
`turbo`, `ultra` plus vendor/product words (`anthropic`, `claude`, `chatgpt`, `codex`, `gemini`, `github`,
`google`, `gpt`, `openai`). Any other word ("Dupont") makes the name a person.

*Known agent addresses*:

- exact: `noreply@anthropic.com`, `no-reply@anthropic.com`, `noreply@openai.com`, `codex@openai.com`,
  `copilot@github.com`, `cursoragent@cursor.com`, `noreply@cursor.com`, `noreply@aider.chat`, `aider@aider.chat`;
- `noreply@`, `no-reply@` or `bot@` at `anthropic.com`, `openai.com`, `cursor.com`, `cursor.sh`, `aider.chat`,
  `cognition.ai`;
- GitHub no-reply addresses (`<id>+<login>@users.noreply.github.com`) of the `Copilot` account, or of a bot app
  (`<login>[bot]`) whose login contains `claude`, `copilot`, `codex`, `openai`, `chatgpt`, `gemini`, `cursor`,
  `devin`, `jules`, `aider`, `openhands` or `anthropic`. Other bots (`dependabot[bot]`) and human GitHub logins
  are kept.

## Signature lines

A line is an agent footer only when the **whole line** is: optional leading whitespace/emoji, then
`Generated with`, `Generated by` or `Generated using`, then one of Claude Code, Claude, Codex, OpenAI Codex,
ChatGPT, GitHub Copilot, Copilot, Cursor, Cursor Agent, Gemini CLI, Gemini, Aider, Devin, Windsurf — optionally as
`[Product]`, optionally followed by `(link)` — and optional `.`/`!`.

| Line | Removed? |
|---|---|
| `🤖 Generated with [Claude Code](https://claude.com/claude-code)` | yes |
| `Generated with Claude Code.` | yes |
| `Generated by GitHub Copilot` | yes |
| `fix: strip the "🤖 Generated with Claude Code" line` (subject) | no — subject, and only a mention |
| `The line "Generated with [Claude Code](...)" stayed.` | no — a sentence |
| `> Generated with Claude Code` / `- Generated with Claude Code` / `"Generated with Claude Code"` | no — quoted or listed text |
| `Generated with Claude Code by Anthropic and edited by me` | no — more than a footer |

## Configuration

```toml
[rules."git.ai-attribution"]
mode = "fix"                      # off | warn | block | fix
policy = "remove-known-ai-only"   # remove-known-ai-only | warn-only | keep
extra_agent_names = ["Acme Bot"]  # treated like built-in agent names
extra_agent_emails = ["bot@acme.dev", "@agents.acme.dev"]   # address, or @domain
extra_signature_patterns = ["Assisted-by: *"]               # whole-line, case-insensitive; * and ? wildcards
# comment_char = "#"              # default: Git's core.commentChar, else '#'
```

| Mode / policy | `remove-known-ai-only` | `warn-only` | `keep` |
|---|---|---|---|
| `fix` | removes, reports what was removed | reports, never edits | nothing |
| `warn` | reports | reports | nothing |
| `block` | reports and fails the commit (exit 1) | same | nothing |

Validation (`config validate`): unknown options, an unknown policy, a `comment_char` that is not one non-space
character, non-string list entries, an email without `@`, and signature patterns with fewer than three literal
characters (so `*` can never delete every line) or longer than 200 characters are errors. Invalid patterns are
ignored at runtime.

## Limits and false positives

- It recognises *known* agents; an agent that signs as an arbitrary human-looking name with a personal address is
  not detected. Add it with `extra_agent_names` / `extra_agent_emails`.
- A person whose display name is exactly an agent product name ("Cursor", "Codex") with no surname is treated as
  that agent. Use a surname, or `policy = "warn-only"` for that repository.
- A bare ambiguous first name with no address (`Co-authored-by: Claude`) is removed, because a valid Git trailer
  for a person has an address.
- Only `Co-authored-by` trailers and footer lines are examined; other trailers (`Signed-off-by`, `Reviewed-by`)
  are never touched unless you add a pattern.
- Hooks can be skipped (`git commit --no-verify`); the rule is a cleanup aid, not a control.

## Español

Elimina la atribución que agregan los agentes de IA a los mensajes de commit — trailers `Co-Authored-By:` de
agentes conocidos y pies de línea completa "Generated with …" — y conserva todo lo demás: coautores humanos,
trailers no relacionados y el texto normal que menciona Claude, ChatGPT, Codex u otro producto.

Es el sucesor de [no-ai-coauthor](../migration/no-ai-couathor.md#español).

| | |
|---|---|
| Id / versión | `git.ai-attribution` / 1.0.0 |
| Objetivo | mensajes de commit (hook `commit-msg`, `reporinse hook git commit-msg <archivo>`) |
| Modos | `off`, `warn`, `block`, `fix` — por defecto **`fix`** |
| Riesgo / prioridad | bajo / P0 |

### Qué cambia

Solo borra líneas completas. Todo lo demás — saltos CRLF o LF, BOM UTF-8, Unicode, sangrías, líneas en blanco
que tú escribiste — queda byte a byte. Lo único extra que borra son las líneas en blanco que una eliminación deja
duplicadas (dos se vuelven una) o colgando al final. Si el mensaje no terminaba en salto de línea, sigue sin
terminar en él. Ejecutarla dos veces no cambia nada la segunda vez.

Nunca toca: la línea de asunto (primera línea no vacía), las líneas de comentario de Git (`#` o
`core.commentChar` / `core.commentString`), lo que va debajo de la línea de tijeras de `git commit -v`, el
autor, el committer, firmas GPG/SSH ni commits que ya están en el historial.

### Tabla de decisión de coautores

| Nombre | Dirección | Decisión | Ejemplo |
|---|---|---|---|
| cualquiera | dirección conocida de agente | **eliminar** | `Claude <noreply@anthropic.com>` |
| nombre de agente, solo o con palabras de modelo/versión | cualquiera | **eliminar** | `Claude Code`, `Claude Opus 4.5`, `aider (gpt-4o)` |
| nombre propio ambiguo solo (`Claude`, `Devin`, `Gemini`, `Jules`) | ninguna | **eliminar** | `Co-authored-by: Claude` |
| nombre propio ambiguo solo | otra dirección | **conservar** (se avisa con `--verbose`) | `Claude <claude@dupont.fr>` |
| palabra de agente + otras palabras | no es de agente | **conservar** | `Claude Dupont <claude@dupont.fr>` |
| cualquier otro | no es de agente | **conservar** | `Ana <ana@example.com>`, `Jane <jane@anthropic.com>` |

Las listas de nombres, palabras de modelo y direcciones conocidas son las de la sección en inglés (son datos, no
texto traducible). Una persona llamada "Claude Dupont" **nunca** se elimina por coincidencia superficial.

### Líneas de firma

Una línea es pie de agente solo si **la línea completa** es: espacios/emoji opcionales, `Generated with`,
`Generated by` o `Generated using`, un producto conocido (opcionalmente como `[Producto]` y seguido de
`(enlace)`) y `.`/`!` opcionales. Una frase que lo menciona, una cita (`> …`), un elemento de lista (`- …`) o
el asunto del commit se conservan. Regresión cubierta: el asunto
`fix: strip the "🤖 Generated with Claude Code" line` sobrevive.

### Configuración

```toml
[rules."git.ai-attribution"]
mode = "fix"                      # off | warn | block | fix
policy = "remove-known-ai-only"   # remove-known-ai-only | warn-only | keep
extra_agent_names = ["Acme Bot"]
extra_agent_emails = ["bot@acme.dev", "@agents.acme.dev"]
extra_signature_patterns = ["Assisted-by: *"]   # línea completa, sin distinguir mayúsculas; comodines * y ?
```

- `remove-known-ai-only`: en `fix` elimina e informa; en `warn` informa; en `block` informa y falla el commit.
- `warn-only`: solo informa, nunca edita.
- `keep`: acepta toda atribución, sin hallazgos.

`config validate` rechaza opciones desconocidas, políticas inválidas, correos sin `@` y patrones con menos de
tres caracteres literales (así `*` jamás borra todas las líneas).

### Límites y falsos positivos

- Solo reconoce agentes *conocidos*; amplía la lista con `extra_agent_names` / `extra_agent_emails`.
- Una persona cuyo nombre visible es exactamente un producto ("Cursor", "Codex") sin apellido se trata como ese
  agente; usa apellido o `policy = "warn-only"`.
- `Co-authored-by: Claude` sin dirección se elimina: un trailer válido de una persona lleva dirección.
- `git commit --no-verify` omite los hooks; es una ayuda de limpieza, no un control de seguridad.

OpenCode, DeepSeek and DeepSeek Harness are recognized exact agent display names and standalone footer products. Human co-authors with different names remain intact. Real Git commit coverage: `opencode_and_deepseek_commit_trailers_are_removed_but_humans_survive`.
