# Migrating from no-ai-coauthor

[no-ai-coauthor](https://github.com/robgallardof/no-ai-couathor) is a single `commit-msg` hook (POSIX `sh` +
`grep` + `awk`) that removes AI `Co-Authored-By` trailers and "Generated with Claude Code" lines.
`git.ai-attribution` is its successor: same goal, stricter about humans, configurable, and installed with a
manifest so it can coexist with other hooks and be removed exactly. [Español](#español)

## What is automated and what is manual

| Step | Automated? |
|---|---|
| Detect the old hook in a repository's hooks directory (it contains the word `no-ai-coauthor`) | yes — `install` notes it |
| Keep it working while RepoRinse is installed (repo scope) | yes — it is chained and runs first |
| Restore it byte-for-byte on `reporinse uninstall` | yes |
| Detect the old **global** install (`core.hooksPath` → `~/.config/git/hooks`) | yes — `install --scope user` stops with exit 4 and says how to retire it |
| Remove the old hook / unset its global `core.hooksPath` | **manual**, with the old project's own uninstaller (RepoRinse never deletes a hook it did not write) |

These paths are covered by `tests/git_migration.rs`, which uses a byte copy of the old hook
(`tests/fixtures/git/no-ai-coauthor/commit-msg`).

## Per repository (the old `install.sh --repo PATH`)

```sh
cd PATH
reporinse install --provider git --scope repo --only git.ai-attribution
```

The old hook becomes `.git/hooks/commit-msg.reporinse-chained` and still runs first; RepoRinse runs after it.
Human co-authors such as `Ana <ana@example.com>` are kept by both. To drop the old hook completely (recommended,
because its regex also removes people named Claude — see below):

```sh
reporinse uninstall --provider git --scope repo                 # restores the old hook exactly
/path/to/no-ai-couathor/install.sh --uninstall --repo .          # or: rm .git/hooks/commit-msg
reporinse install --provider git --scope repo --only git.ai-attribution
```

## Global (the old `install.sh` / `install.ps1` without `--repo`)

The old global install sets `git config --global core.hooksPath ~/.config/git/hooks`. RepoRinse never overrides
an existing global `core.hooksPath`, so `reporinse install --scope user` reports a conflict (exit 4). Retire the
old hook first, then install:

```sh
/path/to/no-ai-couathor/install.sh --uninstall        # PowerShell: .\install.ps1 -Uninstall
reporinse install --provider git --scope user --only git.ai-attribution
```

The old uninstaller restores any `commit-msg.bak` it made. Unlike the old global hook, RepoRinse's user-scope
hooks also run each repository's own `.git/hooks/<hook>`, so per-repository hooks keep working.

## Behaviour differences (intentional)

| Case | no-ai-coauthor | RepoRinse `git.ai-attribution` |
|---|---|---|
| `Co-authored-by: Claude Dupont <claude@dupont.fr>` | removed (regex matched "claude") | **kept** — a person |
| `Co-authored-by: Claude <claude@dupont.fr>` | removed | **kept** (ambiguous first name with a personal address) |
| `Co-authored-by: Jane <jane@anthropic.com>` / `Ana <ana@cursor-fans.org>` | removed (domain contains a brand) | **kept** |
| Agents outside the 8 old words (Aider, Devin AI, Windsurf, Amazon Q, OpenHands, Jules, `claude[bot]` GitHub apps) | kept | removed |
| `Generated by GitHub Copilot`, `Generated with Codex` | kept (only Claude Code was a footer) | removed |
| `- Generated with Claude Code`, `> Generated with Claude Code` (list / quote) | removed (any non-alphanumeric prefix) | **kept** (only whitespace/emoji may precede) |
| A subject line that is exactly a footer | removed (empty message, Git aborts) | kept — the subject is never removed |
| Repeated blank lines you wrote in the body | collapsed everywhere | kept; only blank lines left by a removal are collapsed |
| Trailing blank lines when nothing was removed | trimmed | untouched (Git's own cleanup still applies) |
| Lines below the `git commit -v` scissors line | processed | ignored |
| Configuration, `warn`/`block` modes, report on stderr | none, silent | yes |
| Existing `commit-msg` hook at install | moved to `.bak`, **stopped running** | chained, keeps running, restored on uninstall |

Same as before: case-insensitive matching, the four cases of the old `test.sh` (ported in
`tests/git_hooks.rs::ported_no_ai_coauthor_cases`), `--amend`/merge messages cleaned, `--no-verify` skips it, no
history rewrite.

## Español

[no-ai-coauthor](https://github.com/robgallardof/no-ai-couathor) es un único hook `commit-msg` que elimina
trailers `Co-Authored-By` de IA y líneas "Generated with Claude Code". `git.ai-attribution` es su sucesor:
mismo objetivo, más estricto con las personas, configurable, e instalado con un manifest para convivir con otros
hooks y desinstalarse con exactitud.

### Qué está automatizado

- Detectar el hook antiguo en el directorio de hooks de un repo: **sí** (`install` lo indica).
- Mantenerlo funcionando mientras RepoRinse está instalado (alcance repo): **sí**, se encadena y corre primero.
- Restaurarlo byte a byte con `reporinse uninstall`: **sí**.
- Detectar la instalación **global** antigua (`core.hooksPath` → `~/.config/git/hooks`): **sí**,
  `install --scope user` se detiene con código 4 y explica cómo retirarla.
- Borrar el hook antiguo o quitar su `core.hooksPath` global: **manual**, con el desinstalador del proyecto
  antiguo (RepoRinse nunca borra un hook que no escribió).

Todo esto está cubierto por `tests/git_migration.rs`, que usa una copia exacta del hook antiguo.

### Por repositorio

```sh
reporinse install --provider git --scope repo --only git.ai-attribution
```

El hook antiguo pasa a `.git/hooks/commit-msg.reporinse-chained` y sigue corriendo primero. Para retirarlo del
todo (recomendado, porque su regex también borra a personas llamadas Claude):

```sh
reporinse uninstall --provider git --scope repo
/ruta/a/no-ai-couathor/install.sh --uninstall --repo .
reporinse install --provider git --scope repo --only git.ai-attribution
```

### Global

```sh
/ruta/a/no-ai-couathor/install.sh --uninstall        # PowerShell: .\install.ps1 -Uninstall
reporinse install --provider git --scope user --only git.ai-attribution
```

### Diferencias de comportamiento (intencionales)

- Se **conservan** coautores humanos cuyo nombre o dominio contiene una marca (`Claude Dupont`,
  `Claude <claude@dupont.fr>`, `Jane <jane@anthropic.com>`); el hook antiguo los borraba.
- Se reconocen más agentes (Aider, Devin AI, Windsurf, Amazon Q, OpenHands, Jules, apps `[bot]` de GitHub) y más
  pies (`Generated by GitHub Copilot`).
- Una línea citada o de lista (`> …`, `- …`) se conserva; el asunto nunca se elimina.
- Solo se colapsan las líneas en blanco que deja una eliminación; tus líneas en blanco se respetan.
- Hay configuración, modos `warn`/`block` y aviso en stderr.
- Un hook `commit-msg` previo ya no se aparta a `.bak` (y deja de correr): se encadena y se restaura al
  desinstalar.
